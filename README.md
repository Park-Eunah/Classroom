# 강의실 대여 프로토타입

Java 25의 기본 HTTP 서버로 만든 학습용 웹 프로토타입입니다. 외부 라이브러리나 데이터베이스 설치 없이 실행할 수 있으며 데이터는 서버를 종료하면 초기화됩니다.

## 실행

Windows PowerShell에서 이 폴더로 이동한 뒤 실행:

```powershell
.\run.ps1
```

브라우저에서 http://localhost:8080 을 엽니다. 서버를 끄려면 실행 중인 창에서 Ctrl+C를 누릅니다.

메인 화면은 로그인 화면입니다. 테스트 계정은 학생 `student01 / student123`, 강의실 관리자 `manager01 / manager123`, 시스템 관리자 `admin01 / admin123`입니다. 로그인 후 계정 역할에 맞는 화면으로 이동합니다.

학생 신청은 월~금 주간 달력에서 날짜 선택 → 시간 바에서 30분 단위로 직접 선택(최대 2시간) → 신청 가능 강의실 조회 → 목적과 추가 정보 입력 순서입니다. 날짜·시간을 바꿀 때마다 고정 수업 및 기존 신청과 겹치지 않는 강의실만 표시합니다. 강의실 관리자 화면은 강의실 목록과 신청 검토 탭으로 나뉩니다. 시스템 관리자는 강의실별 담당 관리자를 지정·해제합니다. 데이터는 서버가 실행되는 동안만 메모리에 저장됩니다.

## 코드 구성

- `app/`: HTTP 서버 시작, 주소별 요청 분배, 공통 HTML 레이아웃
- `view/`: 로그인, 학생, 강의실 관리자, 시스템 관리자 화면과 신청 목록 표시
- `resources/static/styles.css`: 전체 화면 공통 스타일
- `service/`: 로그인·세션, 신청·승인, 강의실 담당 관리자 지정 처리
- `data/`: 강의실과 고정 수업 샘플 데이터
- `model/`: 강의실, 대여 신청, 담당 관리자, 테스트 계정 데이터 모델
