# 강의실 대여 프로토타입

Java 기본 HTTP 서버로 만든 학습용 웹 프로토타입입니다. 로컬에서는 데이터베이스 없이 실행할 수 있고, Render에서는 PostgreSQL에 대여 신청과 강의실 관리자 지정을 저장합니다.

## 실행

Windows PowerShell에서 이 폴더로 이동한 뒤 실행:

```powershell
.\run.ps1
```

브라우저에서 http://localhost:8080 을 엽니다. 서버를 끄려면 실행 중인 창에서 Ctrl+C를 누릅니다.

메인 화면은 로그인 화면입니다. 테스트 계정은 학생 `student01 / student123`, 강의실 관리자 `관리자1`, `관리자2`, `관리자3` (비밀번호 `manager123`), 시스템 관리자 `admin01 / admin123`입니다. 로그인 후 계정 역할에 맞는 화면으로 이동합니다.

학생 신청은 월~금 주간 달력에서 날짜 선택 → 시간 바에서 30분 단위로 직접 선택(최대 2시간) → 신청 가능 강의실 조회 → 목적과 추가 정보 입력 순서입니다. 날짜·시간을 바꿀 때마다 고정 수업 및 기존 신청과 겹치지 않는 강의실만 표시합니다. 강의실 관리자 화면은 강의실 목록과 신청 검토 탭으로 나뉩니다. 시스템 관리자는 강의실별 담당 관리자를 지정·해제합니다.

## Render 배포

이 저장소는 `Dockerfile`로 빌드되며 웹 서버는 Render가 지정하는 `PORT`에서 실행됩니다. `/healthz`는 Render의 상태 확인 경로입니다. `DATABASE_URL`을 설정하면 첫 실행 때 PostgreSQL 테이블을 만들고 기존 신청과 관리자 지정을 불러옵니다. 이후 신청·승인·반려·담당자 변경이 데이터베이스에 저장됩니다. `DATABASE_URL`이 없는 로컬 실행은 메모리 모드입니다.

1. 이 저장소의 `proto` 브랜치를 GitHub에 push합니다.
2. Render에서 PostgreSQL 데이터베이스와 Docker 웹 서비스를 만들고 두 서비스의 리전을 같게 설정합니다.
3. 웹 서비스 환경변수 `DATABASE_URL`에 PostgreSQL의 Internal Database URL을 연결하고, Health Check Path를 `/healthz`로 설정합니다.
4. 배포가 완료되면 제공된 `onrender.com` 주소에서 시연합니다.

무료 웹 서비스는 일정 시간 요청이 없으면 잠들었다가 다음 요청에 다시 시작할 수 있습니다. 무료 PostgreSQL은 생성 후 30일에 만료되고 무료 백업이 제공되지 않으므로, 시연용 데이터를 장기 보관하는 용도로 사용하지 마세요. 이 구성은 시연용 계정과 비밀번호를 포함한 프로토타입입니다.

## 코드 구성

- `app/`: HTTP 서버 시작, 주소별 요청 분배, 공통 HTML 레이아웃
- `data/Database.java`: PostgreSQL 스키마 초기화와 영속 데이터 저장
- `view/`: 로그인, 학생, 강의실 관리자, 시스템 관리자 화면과 신청 목록 표시
- `resources/static/styles.css`: 전체 화면 공통 스타일
- `service/`: 로그인·세션, 신청·승인, 강의실 담당 관리자 지정 처리
- `data/`: 강의실과 고정 수업 샘플 데이터
- `model/`: 강의실, 대여 신청, 담당 관리자, 테스트 계정 데이터 모델
